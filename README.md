# practica-viga
Laboratorio de Matemáticas. Módulo: Aplicaciones de transformada de Laplace.

Autores:
Elena Carreras Casanova
Fernán Camilo Osorio Guzmán
Christian Vanhille

Se evalua la aplicación de la Transformada de Laplace a problemas de aplicación. En este caso se planteará la simulación de deflexión de una viga empotrada en dos puntos, con una carga puntual.
